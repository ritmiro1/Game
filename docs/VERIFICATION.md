# Отчёт о проверке сборки

Среда сборки: Linux x86_64, 2 vCPU, без GPU и без OpenGL/X11.
Поэтому проверка велась компиляцией, статическим анализом и безэкранными прогонами.

## 1. Компиляция

| Цель | Результат |
|---|---|
| Windows x64 (`zig cc -target x86_64-windows-gnu`, raylib 5.5) | собирается, PE64, подсистема Windows GUI |
| Нативные тесты логики (`gcc -std=c99 -Wall -Wextra`) | 0 предупреждений, 0 ошибок |
| Безэкранный прогон игры (заглушки raylib + ASan/UBSan) | 0 ошибок, 0 утечек-обращений |

## 2. Логика мира (tests/sim_test.c) — 19 проверок, 0 ошибок

Рельеф, суша/вода, ходьба, бег и выносливость, посадка в лодку, тяга лодки,
заброс, поклёвка, вываживание, инвентарь, продажа, магазин, квесты, достижения,
сохранение/загрузка, 10-минутный прогон (600 с модельного времени) без падений.

## 3. Полный прогон игры без GPU (tests/ui_smoke.c) — 20 проверок, 0 ошибок

* архив ресурсов: 63 файла, чтение шрифта, текстуры, звука, обработка отсутствующего файла;
* построение рельефа, 36 батчей растительности, 13 моделей рыб, части персонажа;
* отрисовка: титульный экран, HUD, пауза, настройки, журнал (4 вкладки), магазин,
  диалоги, достижения, загрузка, ночь/шторм/подводная камера;
* полный цикл рыбалки через интерфейс: посадка в лодку → заброс → поклёвка →
  подсечка → вываживание → запись в садок;
* звуковая подсистема, сохранение и загрузка, 600 кадров всех экранов.

## 4. Ресурсы внутри .exe

Архив дописан в конец исполняемого файла. Проверено чтением всех 63 записей
непосредственно из готового `.exe`: у каждой записи корректная сигнатура
(`RIFF` для WAV, `\x89PNG` для PNG, `\x00\x01\x00\x00` для TTF).
База архива вычисляется из футера, поэтому смещения не зависят от размера `.exe`.

## 5. Устойчивость запуска

* Окно отрисовывает первый кадр до любой тяжёлой инициализации и продолжает
  перерисовываться между этапами (колбэк прогресса в сборщике моделей) —
  Windows не помечает приложение как «Не отвечает».
* Каждый этап пишется в `startup.log` рядом с `.exe` (включая сообщения raylib
  через `SetTraceLogCallback`), с отметками времени.
* Звук инициализируется после первого кадра и только если устройство доступно;
  при недоступности устройства игра работает без звука.
* Безопасный режим (`--safe` или файл `safe.txt`) отключает звук и пост-обработку.
* При недоступности OpenGL 3.3 показывается окно с сообщением, а не пустой экран.
* Авто-качество: пробный кадр под экраном загрузки замеряется, и по его времени
  выбирается внутренний масштаб буфера (100 / 70 / 50%), дальность отсечения декора
  и пост-обработка; при среднем кадре дольше 42 мс качество понижается ещё раз.
* В `startup.log` пишутся GL renderer/version, время пробного кадра, все кадры дольше
  500 мс и FPS каждые 300 кадров — по журналу видно, упирается ли игра в видеокарту.

## 6. Графика: что проверено и что нет

Проверено: загрузка шейдеров из архива, имена всех юниформов сверены с исходниками
шейдеров (расхождений нет), порядок проходов пост-обработки, размеры буферов,
корректный откат при недоступности шейдеров (`litOk/waterOk/skyOk` → материалы
по умолчанию, пост-обработка отключается).

Не проверено в этой среде: фактическая картинка на экране — нет GPU, нет OpenGL,
нет дисплея. Логика отрисовки исполнена 600+ раз с заглушками без падений,
но визуальная оценка требует запуска на Windows с видеокартой.
