# Плеер для плавного просмотра

## Копии

- Full HD 1080×1920, H.264 Main 4.0 — рекомендуемый скачиваемый файл, 16,9 МБ.
- 720×1280, H.264 Main 3.1 — стандартный режим плеера, 4,7 МБ.
- 432×768, H.264 Baseline 3.0, без B-кадров — экономный режим, 2,3 МБ.

Все копии содержат 1518 кадров при 30 кадрах/с и неизменённые исходные AAC-пакеты. Полный кадр и поля сохранены. Это уменьшенные версии, а не полный 16K с обещанием аппаратного ускорения. По сравнению с 8640×15360 в одном 720p-кадре в 144 раза меньше пикселей; это не означает ровно 144-кратного ускорения на конкретном устройстве.

Вложения для скачивания перечислены в `downloads/README.md`. `downloads/playback-validation.json` — исходный отчёт успешной сборки, с хешами, параметрами и результатами полного декодирования. Показатели скорости в нём относятся только к GitHub runner.

## Почему изменён плеер

Раньше даже HD-превью запрашивалось через внешние перенаправления GitHub. Теперь медиазапросы идут на тот же сервер:

- `/watch.mp4` — проверенный 720p-файл из репозитория;
- `/economy.mp4` — локальная экономная копия;
- поддерживаются GET, HEAD, одиночные диапазоны байтов и перемотка;
- для версионных URL используются ETag и длительное кеширование; HTML не кешируется;
- 16K и AV1 отсутствуют в списке автоматически загружаемых источников;
- `playsinline`, обычные браузерные controls, никаких внешних скриптов и графических фильтров.

При трёхсекундной буферизации или двух последовательных окнах с заметными пропусками кадров плеер может переключиться с 720p на 432p, сохраняя позицию. При паузе, перемотке или скрытой вкладке автоматического понижения нет. Ручной выбор отключает автоматику. При `Save-Data` или очень медленной сети можно сразу начать с экономного режима.

## Запуск

```bash
python -m pip install imageio-ffmpeg==0.8.1
python video-tools/optimize_playback.py \
  --economy-from720 downloads/armorypass-ejoy-smooth-720p.mp4 \
  --output-dir "$HOME/.cache/video-tools/playback"
python video-tools/player_server.py \
  --economy-file "$HOME/.cache/video-tools/playback/armorypass-ejoy-economy-432p.mp4" \
  --port 8001
```

Сервер слушает `0.0.0.0` и допускает проксируемый preview-host. Браузер использует относительные адреса, не `localhost`. Экономная локальная копия пересоздаётся из проверенного 720p; её байты могут отличаться от вложения релиза из-за различий CPU или сборки FFmpeg. В текущей сессии она отдельно проверена полным декодированием, по размеру кадра, AVC-профилю, BT.709, fast-start и AAC.

## Проверки кода

```bash
python -m unittest discover -s video-tools -p 'test_play*.py' -v
node --test video-tools/player.test.cjs
```

Проверяются допустимость AVC-уровней, диапазоны HTTP, HEAD, ETag, кеширование, ручной выбор, сохранение позиции, медленная сеть, буферизация и пропуски кадров. Эти проверки не доказывают плавность в браузере пользователя: аппаратное декодирование, энергосбережение и качество сети зависят от устройства.
