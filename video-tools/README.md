# Техническая сборка вертикальной версии 16K

Выходной холст: **8640×15360**, AV1 в MP4, 30 кадров/с, 1518 кадров. Это увеличение исходника 480×636, **не нативная 16K-детализация**.

## Почему отдельная сборка

В локальной среде доступно около 4 ГБ оперативной памяти. Короткий AV1-тест из трёх настоящих 16K-кадров прошёл кодирование и декодирование, но более длинные последовательности превысили безопасный бюджет памяти. HEVC также оказался слишком требовательным; H.264 записал тест только с предупреждением о превышении стандарта уровня. Поэтому полный рендер вынесен в стандартный Linux runner GitHub Actions публичного репозитория. Локальные 4K-файлы не заменяются.

## Обработка

- Умеренное подавление блоков, временного шума и цветовых ступеней.
- Ограниченная коррекция размытия только по яркости.
- ESPCN×4: 55% результата модели, 45% кубической интерполяции; лёгкое двустороннее сглаживание.
- Сохранение полного кадра и прежних полей; финальное увеличение до 8640×15360.
- AV1, CRF 18, без принудительного ограничения размера ценой дополнительного сжатия. Оригинальная AAC-дорожка копируется.
- Новая анатомия, новые действия и промежуточные кадры не создаются. Сглаживание может смягчить исходную текстуру; появление новых достоверных деталей не обещается.

Модель: [TF-ESPCN, ESPCN×4](https://github.com/fannymonori/TF-ESPCN/blob/a899033b12cd0400454fb5777600883a9d7e86c3/export/ESPCN_x4.pb), загружается по закреплённой ревизии и проверяется по SHA-256. Код не скачивает и не запускает посторонние программы из видеометаданных.

## Проверки и публикация

Скрипт проверяет хеш входного файла и модели, размеры, BT.709, fast-start, полное декодирование всех кадров и совпадение исходной AAC-дорожки. После проверки workflow публикует результат отдельным release-asset, не меняя прежний релиз приложения и не добавляя большой выходной MP4 в Git. Также создаются лёгкая HD-копия и JSON-отчёт.

**Наличие workflow ещё не означает, что полный рендер завершён.** Фактический статус нужно проверять в Actions и по опубликованному отчёту. Обычный браузер или телефон могут не воспроизводить 16K AV1; HD-копия предназначена только для просмотра, а не замены полного файла.

Запуск на машине с достаточной памятью:

```bash
python -m pip install -r video-tools/requirements.txt
python video-tools/render_16k.py \
  --source video-tools/input/armorypass-ejoy.mp4 \
  --output /path/to/output/armorypass-ejoy-16k.mp4
```
