# Техническая сборка вертикальной версии 16K

Выходной холст: **8640×15360**, AV1 в MP4, 30 кадров/с, 1518 кадров. Это увеличение исходника 480×636, **не нативная 16K-детализация**.

## Почему отдельная сборка

В локальной среде доступно около 4 ГБ оперативной памяти. Короткий AV1-тест из трёх настоящих 16K-кадров прошёл кодирование и декодирование, но более длинные последовательности превысили безопасный бюджет памяти. HEVC также оказался слишком требовательным; H.264 записал тест только с предупреждением о превышении стандарта уровня. Поэтому полный рендер вынесен в стандартный Linux runner GitHub Actions публичного репозитория. Локальные 4K-файлы не заменяются.

## Обработка

- Умеренное подавление блоков, временного шума и цветовых ступеней.
- Ограниченная коррекция размытия только по яркости.
- ESPCN×4: 55% результата модели, 45% кубической интерполяции; лёгкое двустороннее сглаживание.
- Сохранение полного кадра и прежних полей; финальное увеличение до 8640×15360.
- AV1, CRF 18, без принудительного ограничения размера ценой дополнительного сжатия. Оригинальная AAC-дорожка копируется.
- Новая анатомия, новые действия и промежуточные кадры не создаются. Сглаживание может смягчить исходную текстуру; появление новых достоверных деталей не обещается.

Модель: [TF-ESPCN, ESPCN×4](https://github.com/fannymonori/TF-ESPCN/blob/a899033b12cd0400454fb5777600883a9d7e86c3/export/ESPCN_x4.pb), загружается по закреплённой ревизии и проверяется по SHA-256. Код не скачивает и не запускает посторонние программы из видеометаданных.

## Проверки и публикация

Скрипт проверяет хеш входного файла и модели, размеры, BT.709, fast-start, полное декодирование всех кадров и совпадение исходной AAC-дорожки. После проверки workflow публикует результат отдельным release-asset, не меняя прежний релиз приложения и не добавляя большой выходной MP4 в Git. Также создаются лёгкая HD-копия и JSON-отчёт.

**Полный рендер завершён успешно**: [запуск 42899254599](https://github.com/ritmiro1/Game/actions/runs/42899254599), ревизия `b18439b328c9bdf5964b6862478706a4b8160265`. Итоговый 16K MP4 — 235 982 991 байт, SHA-256 `a1e91b164efba3b1f7ae278b2c8158b56e560a7834be40afcc50de7c2a7356da`. Технический отчёт опубликован в отдельном релизе; ссылки находятся в `downloads/README.md`. Обычный браузер или телефон могут не воспроизводить 16K AV1; HD-копия предназначена только для просмотра, а не замены полного файла.

Запуск на машине с достаточной памятью:

```bash
python -m pip install -r video-tools/requirements.txt
python video-tools/render_16k.py \
  --source video-tools/input/armorypass-ejoy.mp4 \
  --output /path/to/output/armorypass-ejoy-16k.mp4
```

## Плавный просмотр вместо тяжёлого 16K

После жалобы на задержки добавлены `optimize_playback.py` и отдельный workflow `video-playback.yml`. Из полного 16K изготовлены H.264-копии 1080×1920, 720×1280 и 432×768. Все кадры и AAC сохранены; новые детали не добавлялись. Сборка [43022653980](https://github.com/ritmiro1/Game/actions/runs/43022653980) завершена успешно. Большие копии находятся во вложениях отдельного релиза, а небольшой основной 720p-файл сохранён в `downloads` для прямой отдачи.

Плеер `player_server.py` использует только локальные H.264-копии, HTTP Range, версионное кеширование и автоматическое облегчение при задержках. Подробности запуска — в `PLAYBACK.md`. Технические тесты не заменяют проверку воспроизведения на конкретном устройстве пользователя.

## Отдельные варианты улучшения и новая комбинация

Выполнен новый проход непосредственно из предоставленного оригинала 480×636: контроль без фильтров, восемь изолированных обработок и совместный сдержанный вариант. Добавлены многокадровая обратная проекция с проверкой движения, мягкая обработка блочных границ, временного и цветового шума, ограниченная коррекция размытия/резкости/цвета и стабилизация только добавленной обработкой разницы. Генеративная модель и интерполяция кадров не применяются; более качественного исходника нет.

Десять полных сравнительных 720p-версий объединены в ZIP 94,4 МБ; комбинация также доступна в Full HD 21,0 МБ, 4K 89,8 МБ и лёгкой 720p 3,96 МБ. Все 13 MP4 проверены полным декодированием, по 1518 кадров и с исходными AAC-пакетами. Публикация [43215938068](https://github.com/ritmiro1/Game/actions/runs/43215938068) завершена успешно; старые файлы и прежний плеер не заменены. Для новой лёгкой версии используйте отдельный MP4 из `downloads`, а не старый плеер.

Методы, ограничения, повторный запуск и восстановление публикации без рендера — в **`VARIANTS.md`**. Размер 4K и ограниченные численные различия не доказывают восстановление настоящих деталей или превосходство комбинации над контролем. Ссылки для скачивания находятся в конце `downloads/README.md`.

## Более сильная очистка из оригинала

`restore_strong.py` добавляет самостоятельный проход с окном до пяти настоящих кадров, проверкой согласованности движения в обе стороны и более сильным, но ограниченным шумоподавлением. Профиль `strong` выбран на шести распределённых по ролику окнах среди трёх профилей, прошедших ограничения сохранения границ, яркости и клиппинга. Генеративной модели, изменения экспозиции и интерполяции кадров нет; усиленная очистка может смягчать настоящую текстуру. Запрос «в 100 раз» не трактуется как измеренное улучшение.

Полная обработка и публикация [43422554903](https://github.com/ritmiro1/Game/actions/runs/43422554903) завершены успешно: 720p — 4,09 МБ, Full HD — 17,36 МБ, 4K — 96,04 МБ. Все три файла экспортированы независимо из lossless-мастера, со всеми 1518 кадрами и исходными AAC-пакетами; полностью декодированы и сверены с digest опубликованных вложений. Старые версии и плеер не заменены. Методы, пределы обработки, точные хеши и восстановление публикации из заранее сохранённого проверенного комплекта описаны в **`RESTORATION.md`**. Открытая локальная 720p-копия создана отдельно и отличается байтами от публикации. Прямые ссылки находятся в конце `downloads/README.md`.
