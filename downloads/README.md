# Финальные версии видео

## Для плавного просмотра

| Версия | Размер кадра | Размер файла | Кодек |
| --- | --- | --- | --- |
| Full HD — рекомендуемая для скачивания | 1080×1920 | 16.9 МБ | H.264 main 4.0 |
| 720p — стандартный режим плеера | 720×1280 | 4.7 МБ | H.264 main 3.1 |
| 432p — экономный режим | 432×768 | 2.3 МБ | H.264 baseline 3.0 |

Эти копии сделаны непосредственно из опубликованного 16K MP4, без новой дорисовки или изменения сцены. Все 1518 кадров, полный кадр и исходная AAC-дорожка сохранены. Используются 8-битный H.264, fast-start и ключевые кадры с интервалом не более двух секунд. Для обычного устройства рекомендуем Full HD, а при задержках — 720p или экономную 432p. Это уменьшенные версии, не ускоренное воспроизведение в полном 16K.

Плеер больше не загружает видео через перенаправления GitHub: основной 720p-файл и экономная копия отдаются с того же сервера, с поддержкой диапазонов байтов, ETag и версионного кеширования. Предусмотрен автоматический переход на экономный режим при длительной буферизации или устойчивых пропусках кадров. Ручной выбор качества отключает автоматический переход. Архивный 16K в плеер не подгружается.

Сборка и проверки: [успешный запуск 43022653980](https://github.com/ritmiro1/Game/actions/runs/43022653980). В `playback-validation.json` сохранены параметры, размеры и контрольные суммы трёх файлов. Для каждого проверены полное декодирование 1518 кадров, AVC profile/level, BT.709, fast-start и совпадение AAC-пакетов. Указанная в отчёте скорость декодирования измерена на runner и не гарантирует скорость конкретного пользовательского устройства. Полные 4K- и 16K-версии не изменены.

## Архивные версии 4K и 16K

| Версия | Размер кадра | Размер файла |
| --- | --- | --- |
| Вертикальная | 2160×3840 | 64.6 МБ |
| Горизонтальная, 16:9 | 3840×2160 | 51.6 МБ |
| Вертикальная, 16K · отдельный релиз | 8640×15360 | 236.0 МБ |

Все три версии содержат все 1518 кадров исходного ролика, около 50,67 с при 30 кадрах/с. Оригинальная дорожка AAC сохранена без усиления и повторного сжатия. Полный исходный кадр не обрезан; пропорции сохранены с округлением размеров до целых чётных пикселей.

## Что изменено

Сборка выполнена заново из оригинала 480×636: умеренное подавление блоков и шума, ограниченное устранение размытия по яркости, ESPCN×4 со смешиванием с обычной интерполяцией. Для двух 4K-файлов использован несжатый временный мастер и конечный H.264 `slow`, CRF 16, BT.709, fast-start. Более агрессивная резкость не применялась: в тестах она подчёркивала артефакты. Это наиболее аккуратный из испытанных вариантов, а не обещание идеальной реконструкции.

В вертикальной версии сохранены чёрные поля сверху и снизу. В версии 16:9 по бокам расположен **статичный художественный фон комнаты**, созданный по отдельному фрагменту стены без людей. Фон не является настоящим продолжением записи. Новые люди, части тела и действия не создавались; центральное изображение сохранено целиком.

**4K здесь — размер выходного кадра, а не нативная детализация съёмки.** Достоверно восстановить отсутствовавшие в оригинале мелкие детали нельзя. Разница с предыдущей обработкой может быть небольшой.

## Проверки

Полное декодирование обоих файлов без ошибок; по 1518 кадров в каждом; исходная AAC-дорожка проверена по SHA-256; проверены размеры, формат цвета и индекс для потокового просмотра. Визуально проверены отдельные фрагменты, а не непрерывное воспроизведение всего ролика.

## Версия 16K

Полная сборка успешно завершена в GitHub Actions: [запуск 42899254599](https://github.com/ritmiro1/Game/actions/runs/42899254599). Отдельный MP4 содержит настоящее кодированное разрешение **8640×15360**, AV1, 30 кадров/с; размер **235 982 991 байт**. Исходный кадр не обрезан, новая анатомия и действия не создавались. Прежние 4K-файлы не изменены.

Для 16K выбран умеренно сглаженный профиль, чтобы не подчёркивать пиксельную структуру и ореолы. Сборка выполнялась заново из оригинала 480×636. Реальной нативной 16K-детализации это не создаёт; сглаживание может смягчать сохранившуюся текстуру. Файл требует совместимого AV1-декодера и больших ресурсов. Для обычного просмотра приложена отдельная HD-копия 720×1280, 4,7 МБ; это не полный 16K-файл.

На runner выполнены полное декодирование 1518 кадров без ошибок, проверка BT.709, fast-start и побитового совпадения AAC-пакетов с исходником. Публикация выполняется только после успешной проверки. SHA-256 MP4 также сверена с digest опубликованного release-asset. В этой локальной среде скачивание вложений релиза перенаправляется на недоступный хост хранения, поэтому локальное воспроизведение итогового 16K не заявляется.

SHA-256 16K: `a1e91b164efba3b1f7ae278b2c8158b56e560a7834be40afcc50de7c2a7356da`.
