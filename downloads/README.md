# Финальные версии видео

| Версия | Размер кадра | Размер файла |
| --- | --- | --- |
| Вертикальная | 2160×3840 | 64.6 МБ |
| Горизонтальная, 16:9 | 3840×2160 | 51.6 МБ |

Обе версии содержат все 1518 кадров исходного ролика, около 50,67 с при 30 кадрах/с. Оригинальная дорожка AAC сохранена без усиления и повторного сжатия. Полный исходный кадр не обрезан; пропорции сохранены с округлением размеров до целых чётных пикселей.

## Что изменено

Сборка выполнена заново из оригинала 480×636: умеренное подавление блоков и шума, ограниченное устранение размытия по яркости, ESPCN×4 со смешиванием с обычной интерполяцией. Для обоих файлов использован несжатый временный мастер и конечный H.264 `slow`, CRF 16, BT.709, fast-start. Более агрессивная резкость не применялась: в тестах она подчёркивала артефакты. Это наиболее аккуратный из испытанных вариантов, а не обещание идеальной реконструкции.

В вертикальной версии сохранены чёрные поля сверху и снизу. В версии 16:9 по бокам расположен **статичный художественный фон комнаты**, созданный по отдельному фрагменту стены без людей. Фон не является настоящим продолжением записи. Новые люди, части тела и действия не создавались; центральное изображение сохранено целиком.

**4K здесь — размер выходного кадра, а не нативная детализация съёмки.** Достоверно восстановить отсутствовавшие в оригинале мелкие детали нельзя. Разница с предыдущей обработкой может быть небольшой.

## Проверки

Полное декодирование обоих файлов без ошибок; по 1518 кадров в каждом; исходная AAC-дорожка проверена по SHA-256; проверены размеры, формат цвета и индекс для потокового просмотра. Визуально проверены отдельные фрагменты, а не непрерывное воспроизведение всего ролика.
